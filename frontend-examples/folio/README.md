# Folio Frontend Reference

The runnable Folio Design Lab is the branch's only frontend visual reference:

- [`design-lab/`](./design-lab/README.md): portable Folio Dashboard, Workspace, and Node Pack.
- [`docs/frontend/13-folio-design-kit.md`](../../docs/frontend/13-folio-design-kit.md): visual catalog and known gaps.
- [`docs/frontend/15-folio-end-to-end-implementation-plan.md`](../../docs/frontend/15-folio-end-to-end-implementation-plan.md): required route, state, and behavior coverage.

The Design Lab is not production code, a sample-data contract, or permission to replace real
StudyAgent state with static content.
