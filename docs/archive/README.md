# Documentation Archive

This directory preserves historical context without presenting it as current guidance.

Archived documents may contain stale status claims, paths, commands, screenshots, and acceptance criteria. Verify all such details against current code and active documentation before reuse.

Archiving does not:

- supersede or revoke an ADR;
- imply that implemented behavior was removed;
- reopen or close a GitHub issue;
- make an old plan the current roadmap.

See [`2026-h1/README.md`](./2026-h1/README.md) for the first cleanup inventory.
